# **App Name**: AcademiaSync

## Core Features:

- Calendar Views: Display events in monthly, weekly, daily, and agenda views.
- Event Filtering: Filter events by category, sub-type, subject, date range, and user role.
- Color-Coded Events: Color-code events based on category or subject, user-configurable.
- Event Details: View event details and subject information on click.
- Role-Based Access: Implement role-based access for students, faculty, admins, and placement coordinators.

## Style Guidelines:

- Primary color: Light blue (#90CAF9) to evoke a sense of trust and calm.
- Background color: Very light blue (#E3F2FD) creating a clean and unobtrusive background.
- Accent color: Soft teal (#80CBC4) to add a touch of sophistication without overwhelming the user.
- Body and headline font: 'Inter' sans-serif for a clean and modern feel suitable for both headlines and body text.
- Use clean, minimalist icons to represent event categories and subjects.
- Maintain a clean and spacious layout to ensure clarity.
